# Browser Plugin

> English | [简体中文](./README.md)

A collection of browser extensions.

## Extensions

### [word2pdf-converter](./word2pdf-converter)

Word → PDF batch converter. Browser extension + Go Native Messaging local bridge that drives Office/WPS through the COM interface. **Windows only.**

- Microsoft Office and WPS Office support, with automatic detection preferring Office
- Real-time conversion progress (SSE push)
- Success/failure file list
- Automatic cleanup of leftover WPS processes

### [lan-file-transfer](./lan-file-transfer)

LAN file transfer tool. Browser extension + Go local HTTP server that lets devices on the same local network exchange files by scanning a QR code.

- Scan to transfer — no configuration needed
- Large file uploads (up to 200 MB)
- Real-time progress (SSE)
- Windows / macOS / Linux support

### [diagram-kit](./diagram-kit)

Chrome / Edge DiagramKit diagram editor extension. Mermaid / Markmap editing with live render preview, PNG/SVG/PDF export, a template library, and diagram archive.

### [chrome-new-tab](./chrome-new-tab)

Chrome / Edge new-tab replacement extension. Multi-search-engine, quick link management, multiple themes, custom backgrounds, and a trending-news module.

### [json-formatter](./json-formatter)

JSON formatting browser extension. Format, minify, and validate JSON directly in the browser.

### [web-translator](./web-translator)

Selection-based translation browser extension. Select a word / phrase / sentence / paragraph and a floating "Translate" button appears — translation only happens when you click it: dictionary-grade detail for words, translation with grammar annotations for sentences, summaries and key points for paragraphs. Powered by the DeepSeek API, with the latest model list fetched automatically on the settings page.
