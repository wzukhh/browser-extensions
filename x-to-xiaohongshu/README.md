# X → 小红书草稿

在 X 页面为帖子截图，并用 DeepSeek 生成小红书标题、可选正文和标签的 Chrome MV3 插件。无需构建、无需后端。

## 安装与使用

1. Chrome 打开 `chrome://extensions/`，开启开发者模式，选择“加载已解压的扩展程序”，指定本文件夹。
2. 打开 `https://x.com/`，在帖子下点“制作小红书草稿”。插件打开编辑页，自动保存初始草稿，展示裁切后的原始截图和 3:4 封面预览。
3. 在编辑页填写 DeepSeek API Key，点“AI 生成标题、正文、标签”。核对标题、截图、来源与事实后保存草稿，或下载两张图片。
4. 点浏览器工具栏中的插件图标可查看已保存的本地草稿。

## 当前范围

- 一次处理一条帖子；截图来自点击时浏览器可见区域。长帖若超出屏幕，编辑页会提示截断，请打开单帖、缩小网页后重新截取。
- 只在用户点击时截图，不后台批量采集。X 网页结构变化可能影响按钮位置及文字提取。
- DeepSeek 使用支持图片输入的 `deepseek-flash`。截图和帖子文字在点击生成时发送给 DeepSeek；Key 保存在 Chrome 本地存储。草稿截图和文案保存在本机 IndexedDB。
- 标题由程序按字素数限制在 20 字以内；生成结果仍需人工核对。插件暂不发布到小红书。

## 权限说明

Chrome 的 `captureVisibleTab` 要求 `activeTab` 或 `<all_urls>` 权限。帖子内按钮无法像工具栏按钮那样授予临时 `activeTab` 权限，因此当前使用 `<all_urls>` 截图权限；插件代码只在 `x.com` 与 `twitter.com` 注入，后台也只接受来自这两个域名的截图请求。另允许请求 DeepSeek API。
