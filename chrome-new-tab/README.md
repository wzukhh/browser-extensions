# New Tab — Chrome / Edge 新标签页

> [English](./README.en.md) | 简体中文

一款简洁美观的浏览器新标签页替换插件。支持多搜索引擎、快捷链接管理、多主题切换、自定义背景与新闻热搜。

## 功能

**搜索** — 集成 Google、百度、Bing、Yandex 等多搜索引擎，支持新增自定义搜索引擎。图标自动获取，离线使用浏览器缓存。

**快捷链接** — 快速访问常用网站，支持添加自定义链接与内置模块（如新闻热搜）。支持添加、编辑、删除、拖拽排序。自动抓取网站图标，支持 `chrome://` 和 `edge://` 内部页面并匹配 emoji 图标。提供批量编辑模式（全选、行选、点选、批量删除）。可从浏览器收藏夹同步导入。

**新闻热搜** — 内置模块，点击快捷方式打开悬浮面板，可切换微博 / 百度 / 抖音热搜榜单，点击条目在新标签页打开。新标签页打开期间每 10 分钟自动刷新；可在设置中关闭热搜数据加载（适合内网环境）。

**主题** — 4 套视觉风格：经典深色、赛博未来（含 CRT 噪波扫描线氛围和不定时故障效果，可单独开关）、杂志极简、深夜暖光。所有主题自动持久化。

**背景** — 渐变背景、纯色背景（支持颜色值复制粘贴）、自定义图片背景。

**工具** — 时钟显示、配置导出/导入（支持文件选择和 URL 在线导入，导出自动忽略背景图片 base64）。

## 数据来源

新闻热搜中的微博、百度、抖音榜单数据均来自 [寻鲸录 API](https://api.xunjinlu.fun/)。感谢 API 提供者。

## 安装

1. 打开 Chrome 或 Edge（Chromium 版），进入扩展管理页面（`chrome://extensions/`）
2. 开启右上角"开发者模式"
3. 从 Release 下载源码压缩包并解压，或 `git clone` 本仓库
4. 点击"加载已解压的扩展程序"，选择 `chrome-new-tab` 文件夹
5. 新建标签页即可使用
